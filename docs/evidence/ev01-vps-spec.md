1. Jalankan `scripts/collect_vps_info.sh` di VPS; tempel keluaran di bawah (tanpa secret).
2. Screenshot konsol: instance ID (boleh disamarkan sebagian), tipe instance, region, IPv4, volume EBS, Security Group.
3. Screenshot Billing: Free Tier/kredit aktif, tanggal pembuatan akun, sisa kredit (tanggal terlihat).
